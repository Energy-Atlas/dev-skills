# Material for MkDocs recipes

Configuration, template override, CSS, and Markdown that implement the spec on Material for MkDocs. Checked on MkDocs
1.6.1 with Material 9.7.7; before reusing a selector on another version, grep the installed theme CSS
(`<venv>/Lib/site-packages/material/templates/assets/stylesheets/main.*.min.css`) for the rule you override, for example:

```bash
sed 's/}/}\n/g' <venv>/Lib/site-packages/material/templates/assets/stylesheets/main.*.min.css | grep -E "md-content__inner|md-path|grid\.cards"
```

Material facts the recipes depend on:

- The root font size is 125% (1rem = 20px), 137.5% from 100em, 150% from 125em. Write sizes in `rem`/`em` so they scale
  with it: 10px = 0.5rem, 11px = 0.55rem, 12px = 0.6rem, 16px = 0.8rem, 18px = 0.9rem, 24px = 1.2rem, 40px = 2rem.
- Breakpoints: the primary sidebar is a drawer below 76.25em; the table of contents shows from 60em; the tabs bar shows
  from 76.25em.
- Sidebars are 12.1rem wide; the article margin is 0.8rem, 1.2rem from 76.25em.
- `hide: [navigation, toc]` in front matter renders the sidebars with the `hidden` attribute. They stay in the DOM before
  `.md-content`, so `.md-sidebar--primary[hidden] ~ .md-content` targets such pages, also after instant navigation.
- `extra_css` loads after the theme's CSS, so equal specificity wins.
- Material remembers the visitor's palette choice in `localStorage` (key `<base path>.__palette`), including the scheme it
  picked from the system preference on the first visit.

## mkdocs.yml

```yaml
theme:
  name: material
  # overrides/main.html preloads the main fonts, so a full page load draws its first frame with them.
  custom_dir: overrides
  # No font host: docs/assets/stylesheets/fonts.css serves the fonts from the site.
  font: false
  features:
    # Instant navigation swaps only the page content, so the header, sidebars, and fonts persist between pages.
    - navigation.instant
    - navigation.instant.progress
    - navigation.tabs
    - navigation.sections
    - navigation.indexes
    - navigation.top
    - navigation.path        # breadcrumbs
    - navigation.footer
    - search.highlight
    - search.suggest
    - content.code.copy
    - toc.follow
  palette:
    - media: "(prefers-color-scheme: light)"
      scheme: default
      primary: custom
      accent: custom
      toggle:
        icon: material/weather-night
        name: Switch to dark mode
    - media: "(prefers-color-scheme: dark)"
      scheme: slate
      primary: custom
      accent: custom
      toggle:
        icon: material/weather-sunny
        name: Switch to light mode

extra_css:
  - assets/stylesheets/fonts.css
  - assets/stylesheets/site.css

markdown_extensions:
  - attr_list     # strips: ## Title { .ui-strip data-index="01" }
  - md_in_html    # hero and grid blocks: <div class="grid cards" markdown>
  - admonition
  - pymdownx.details
```

`navigation.instant` needs `site_url`. Keep the site's existing features and extensions; add, do not replace.

## overrides/main.html

```jinja
{% extends "base.html" %}

{#- Preload the two fonts every page uses, so the first frame is drawn without a font swap. -#}
{% block extrahead %}
  <link rel="preload" href="{{ 'assets/fonts/sans-latin.woff2' | url }}" as="font" type="font/woff2" crossorigin>
  <link rel="preload" href="{{ 'assets/fonts/mono-latin.woff2' | url }}" as="font" type="font/woff2" crossorigin>
{% endblock %}
```

Preload only files that every page uses, or the browser warns about unused preloads. If the project keeps an
ownership table, `overrides/` is hand-maintained.

`unicode-range` values.


### Page frame

`.md-content` carries the two vertical frame rules from 60em up (where the content column has neighbours). `--ui-gutter` must equal Material's article margin (0.8rem, 1.2rem from 76.25em). `--ui-inset-*` equals the sidebar width (12.1rem in Material 9) when a sidebar is hidden by front matter (`hide: [navigation, toc]`), so the text of such a page lines up with pages that have sidebars. The `[dir] .md-main__inner > .md-content > .md-content__inner.md-typeset` selector exists only to outrank Material's `[dir=ltr] .md-sidebar--primary:not([hidden])~.md-content>.md-content__inner` margin rule.

```css
/* Reserve the scrollbar's width on every page, so that moving between short and long pages does not shift the layout. */
html {
  scrollbar-gutter: stable;
}

.md-grid {
  max-width: 76rem;
}

.md-main__inner {
  margin-top: 0;
}

/* The content column is bounded by two thin vertical rules, like the frame of a drawing sheet. */
@media screen and (min-width: 60em) {
  .md-content {
    border-left: 1px solid var(--ui-border-subtle);
    border-right: 1px solid var(--ui-border-subtle);
    min-height: calc(100vh - 4.8rem);
  }
}

.md-sidebar {
  padding-top: 1.6rem;
}

.md-content__inner {
  padding-top: 1.2rem;
}

/*
 * A page that hides a sidebar (a landing page usually hides both) keeps the sidebar's width as an empty margin, without its
 * rule, so its text lines up with the text of every other page. Only the content moves: strips and grids still run
 * from frame to frame. --ui-inset-left and --ui-inset-right hold the empty margins.
 */
.md-content {
  --ui-inset-left: 0rem;
  --ui-inset-right: 0rem;
}

@media screen and (min-width: 76.25em) {
  .md-sidebar--primary[hidden] ~ .md-content {
    --ui-inset-left: 12.1rem;
  }

  .md-sidebar--secondary[hidden] ~ .md-content {
    --ui-inset-right: 12.1rem;
  }
}

[dir] .md-main__inner > .md-content > .md-content__inner.md-typeset,
[dir] .md-main__inner > .md-content > .md-path {
  margin-left: calc(var(--ui-gutter) + var(--ui-inset-left));
  margin-right: calc(var(--ui-gutter) + var(--ui-inset-right));
}
```

### Grids of cells

Restyles Material's `grid cards` Markdown. The outer `div` draws the top and bottom rules frame to frame; the inner list is the CSS grid (inset like the text) and clips each cell's right and bottom rule (drawn with `box-shadow`) at its outer edge, so only internal rules show and empty trailing cells stay blank. Where an inset moves the grid in from the frame, the list draws its own outer edges, offset by 1px to keep the text alignment. A cell whose title is a link is clickable as a whole through a stretched `::after`; other links sit above it. The cell index comes from a CSS counter: letters for `ul`, `01`, `02`, ... for `ol`.

```css
.md-typeset .grid.cards {
  border-bottom: 1px solid var(--ui-border-subtle);
  border-top: 1px solid var(--ui-border-subtle);
  display: block;
  margin: 1.6rem calc(-1 * (var(--ui-gutter) + var(--ui-inset-right))) 1.6rem
    calc(-1 * (var(--ui-gutter) + var(--ui-inset-left)));
  max-width: none;
  padding: 0 var(--ui-inset-right) 0 var(--ui-inset-left);
}

.md-typeset .grid.cards > :is(ul, ol) {
  counter-reset: ui-cell;
  display: grid;
  gap: 0;
  grid-template-columns: repeat(auto-fit, minmax(min(100%, 14rem), 1fr));
  list-style: none;
  margin: 0;
  overflow: hidden;
  padding: 0;
}

/*
 * Where an empty sidebar margin moves the grid in from the frame, the grid closes its outer edge with its own rule,
 * drawn just outside the margin so that the cells' text keeps its alignment.
 */
```

## Markup

### Landing page

```markdown
---
hide:
  - navigation
  - toc
---

<div class="ui-hero" markdown>

# Generate building energy models<br>*at urban scale.*

One or two sentences that say what the project is.

</div>

## Documentation { .ui-strip data-index="01" data-note="Two parts" }

<div class="grid cards" markdown>

-   [User guide](user/index.md)

    Who it is for and what it covers.

    [Open the user guide](user/index.md){ .md-button }

-   [Developer documentation](developer/index.md)

    Who it is for and what it covers.

    [Open the developer documentation](developer/index.md){ .md-button }

</div>

## About { .ui-strip data-index="02" data-note="Research question" }

The page's remaining prose, unchanged.
```

- The `*...*` phrase of the headline becomes the serif italic.
- A cell's first paragraph is its title; when it is a single link, the whole cell becomes clickable.
- No `---` separator inside cells; the index, title, description, and button carry the structure.
- Keep the original landing prose under its own strips rather than deleting it.

### Section index page

```markdown
## Reading order { .ui-strip data-index="01" data-note="First time through" }

<div class="grid cards compact" markdown>

1.  [Getting started](getting-started.md)

    What you need, how to install, and a first example that runs.

2.  [Concepts](concepts.md)

    The words this guide uses.

</div>

## Conventions { .ui-strip data-index="02" data-note="How this guide writes" }
```

- Turn a `1. [Page](page.md): description` list into two paragraphs per item: the link alone, then the description.
  Links inside a description stay clickable and keep their own targets.
- Styling an existing `##` heading as a strip keeps its anchor; check that no page links to a heading you rename.
- A numbered list (`ol`) gives `01`, `02`, ... indices; a bulleted list gives `A`, `B`, ....
